ClearTXT

Strip text down to a clean, safe character set — everything else is removed.

What is kept, and what is removed?

The filter keeps the following characters and deletes everything else:

  • Latin alphabet — a–z and A–Z
  • Digits — 0–9
  • Punctuation — . , ; : ! ? ' " ( ) [ ] { } and friends
  • En dashes & hyphens — - ‐ –
  • Math signs — the ASCII ones only: + - * / = < > % ^
  • Markdown syntax — # * _ ` > | ~ [ ] ( ) ! (all standard ASCII, already kept)
  • Whitespace — spaces, tabs, and line breaks are preserved

Before filtering, the text is retyped — normalized to Unicode NFKC form so ligatures (ﬁ→fi), full-width letters (Ａ→A) and superscripts (²→2) fold into plain forms, and the output is rebuilt as a fresh, canonical string.

Removed: emoji, accented/non-Latin letters (é, ñ, ω, 日), smart “curly” quotes, em dashes, Unicode math symbols (± × ÷ ≤ ≥ √ …), control characters, and all zero-width / invisible characters (ZWSP, ZWJ, BOM, directional marks).
