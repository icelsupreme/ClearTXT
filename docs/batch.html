Fixes & explanation

Choose which fixes to apply, grouped below - each group's checkbox toggles every fix in it at once. A fix that's off leaves its characters untouched; anything none of them can convert is removed. Changing a fix re-cleans every file already added, and preferences are shared with the single-file page.

Always kept: the Latin alphabet (a–z A–Z), digits (0–9), standard punctuation and ASCII math signs (+ - * / = < > % ^), Markdown syntax, and whitespace.
