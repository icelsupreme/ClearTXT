ClearTXT v1.12.1

What's new - a running history of features and fixes.

Single-file Batch Compare

The short version, grouped by release. For the full technical detail behind every change, see CHANGELOG.md in the repo.

1.12.1Compare accuracy fix, take two

  • The 1.11.1 fix for the Compare page's "large near-identical blocks shown as fully changed" bug turned out not to go far enough - it still fell back to fully-changed on realistic long documents, because even a tiny genuine edit (like a bullet point added to a hundred otherwise-untouched lines) produces a large size once "a hundred lines" is multiplied out, tripping the same kind of size limit. The underlying diff algorithm is now the one real diff tools use (an edit-distance-based search, rather than one whose cost depends on the length of the text) - so a small edit stays fast and precise no matter how much unrelated shared text surrounds it.

1.12Tools tab bar

  • Every page's small "back to X" / "go to Y" link is now a persistent tab bar listing all three tools - Single-file, Batch, and Compare - always visible, with the current page's tab highlighted. Any tool is now one click away from any page, not just whichever one happened to be linked before.

1.11.1Compare accuracy fix

  • Fixed the Compare page marking large stretches of near-identical text as fully changed whenever the two files wrapped the same content across a different number of lines (e.g. one long line in File A re-wrapped into two or three shorter lines in File B). The diff now compares each whole changed region at once instead of pairing individual lines by position, so text that's genuinely unchanged - even if it landed on a different line - stays unhighlighted.
  • The Previous/Next-difference navigation and "What's different?" summary now count these regions rather than individual lines, so a single re-wrapped paragraph shows up as one difference instead of a dozen.

1.11Compare two files

  • New Compare page: paste or import two files into the same two-box diff editor as the single-file page, with Previous/Next-difference navigation, character-level highlighting on changed lines, and a report panel showing a percentage-diff figure plus character/word counts and their difference for each file - with a toggle to include or exclude Markdown syntax from those numbers, and Copy/Download buttons for the report.
  • Shares the single-file/batch pages' Fixes panel and preferences, plus a new "Apply cleanup before comparing" toggle to clean both files before diffing, or compare them exactly as imported.

1.10.3Behind-the-scenes cleanup

  • No visible changes - this release is internal cleanup only: less duplicated work re-rendering the input/output boxes while typing, and some duplicated code between pages consolidated into one shared place.

1.10.2Filename fix

  • Fixed a gap where one of the two "hidden text" character ranges could still slip through into an exported, downloaded, or batch-zipped file's own name, even though the other one already couldn't - both are now stripped from filenames the same way.

1.10Unsafe link protocols

  • Added a "Strip unsafe link protocols" option that removes a Markdown link's destination (keeping its visible text) when it doesn't point to a normal web address, email, or phone number - closing off a trick recently used against Windows Notepad's own Markdown mode.
  • Added a note to the Documentation page on why font-based visual spoofing (making text display as something other than what it actually is) doesn't affect anything pasted into ClearTXT.

1.9Download only what changed

  • Batch mode's "Download all" is now "Download changed" - files that were already clean are skipped, instead of being bundled into the .zip unchanged.
  • Added a "Remove unchanged" button to clear already-clean files out of the list in one click.
  • Fixed a spoofed-extension trick (e.g. a right-to-left override making an .exe display as a .txt) that could survive in an exported or downloaded file's own name.

1.8Sitemap

  • Added a sitemap.xml listing every page, and moved robots.txt to where the live site can actually serve it - both were previously missing or unreachable for search engines.

1.7Social sharing card

  • Links to ClearTXT now show a real preview image when shared on social media, Slack, iMessage, etc., instead of no image at all.

1.6Documentation page

  • Added a Documentation page explaining what ClearTXT actively defends against - hidden/invisible characters, bidirectional text spoofing, and look-alike character tricks - and how, linked from every page's footer.

1.5Look-alike character detection

  • Added a "Strip look-alike characters" option that catches the classic domain/brand-spoofing trick of swapping a letter for a similar-looking one from another alphabet (e.g. a Greek "ο" in gοogle.com). Only flags letters mixed mid-word with Latin text - a sentence written entirely in another language is left alone.

1.4Arabic support

  • Added a "Strip Arabic characters" option, the same way Hebrew and Cyrillic are already handled.
  • Arabic text now renders in its own proper typeface instead of a fallback font.

1.3This changelog & sharing

  • Added this changelog page - the short version of what's new, linked from every page's footer.
  • Added a "Share" button that copies the page's link to your clipboard.
  • Fixed a couple of invisible characters (including one used in bidi-direction spoofing tricks) that weren't being caught by "Strip invisible & control characters" when it should have been.

1.2Language options & Cyrillic support

  • Added an option to strip Cyrillic text (Russian, Ukrainian, and more), the same way Hebrew is already handled.
  • Grouped all language/script options together under "Languages & scripts."
  • Fixed a rare bug where certain math symbols (like ℵ, used for aleph-null) could be mistaken for Hebrew letters and removed.

1.1Batch mode

  • Added Batch mode: clean multiple files at once, downloaded individually or all together as a single .zip.
  • Batch downloads now confirm when they're done, and are hardened against unsafe filenames.

1.0Public launch

  • ClearTXT went public, with a proper page title, favicon, and social preview cards.
  • Fixed line numbers drifting out of alignment on large documents.

0.19Icons and polish

  • Every button got a matching icon, plus a subtle visual refresh.

0.18Consistent fonts

  • The whole page now uses the same fonts everywhere, including proper support for Hebrew text.

0.17Restore defaults

  • Added a "Restore defaults" button, and more detailed character/word counts in the sticky footer.

0.15Accessibility

  • Bigger touch targets, clearer focus outlines, and better screen reader support throughout.

0.14Grouped fix options

  • Fix toggles got organized into groups you can turn on or off all at once.

0.12-0.13Jump between changes

  • Added Previous/Next buttons (and keyboard shortcuts) to jump between changed lines, plus a dedicated currency-symbol option.

0.9-0.10Inline highlighting

  • Highlighting moved directly into the text boxes, with a full-row tint on changed lines.
  • Added a choice of em dash replacement, and hardened invisible-character detection against text-spoofing tricks.

0.4-0.8Import, export & invisible characters

  • Added "Import from file" and "Export to file."
  • Invisible/zero-width characters now show as labeled markers instead of disappearing without a trace.
  • Exported files are named after your text's first line.

0.1-0.3Early days

  • Initial release: a simple, safe-character-set text filter.
  • The fixed character filter became configurable, with independent toggles and a full diff view of what changed.
  • Text boxes wrap instead of scrolling sideways; added whitespace cleanup options.
